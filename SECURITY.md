# Security Policy

## Supported Versions

We provide security updates for the following versions of `gowa-php/filament`:

| Version | Supported          |
| ------- | ------------------ |
| 5.x     | :white_check_mark: |
| 4.x     | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within `gowa-php/filament`, please **do not open a public issue**. Disclosing a vulnerability publicly can put users and systems at risk.

Instead, please report the vulnerability privately through one of the following channels:

- **GitHub Private Vulnerability Reporting**: Open a security advisory on GitHub under the **Security** tab of the repository.
- **Email**: Send details to `aguinaldo.tupy@gmail.com`.

### What to Include in Your Report

- A clear description of the vulnerability and its potential impact.
- Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
- Affected version(s) of `gowa-php/filament`, Laravel, and Filament.
- Any suggested remediations or mitigations if known.

## Response Timeline

- **Acknowledgement**: We will acknowledge receipt of your report within **48 hours**.
- **Investigation**: We will investigate the issue and communicate progress with you.
- **Resolution**: Once a fix is verified, a patched release will be published promptly alongside responsible disclosure.

Thank you for helping keep `gowa-php/filament` and its community secure!
